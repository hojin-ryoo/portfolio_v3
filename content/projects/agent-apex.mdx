For my first project at PwC, we created Agent Apex, a platform for demonstrating PwC's AI capabilities by interfacing across all the agents used at the firm.

The application itself is a multi-agent system that routes user queries to specialized AI agents based on the nature of the request. It's designed for enterprise use cases where different questions need different domain expertise (Tax, Advisory, Assurance, etc.)

We delivered the entire project in a month—from concept to a production-ready demo. That tight timeline meant close collaboration, clear priorities, and a lot of iteration. The payoff was showcasing Agent Apex at PwC's annual partner summit, where we displayed the application to firm leadership and partners. It was a great opportunity to put PwC's AI library and agent capabilities in front of the people who shape the firm's strategy.
